Privacy Policy

Last updated: 2026-10-15

AiWong Fitness is a personal health dashboard operated by Victor Wong for his own use. It integrates with the Google Health API (Fitbit Air data) and the WHOOP API to display fitness, recovery, sleep, activity and body-measurement data belonging to the operator. The application has a single user: the operator.

Data We Access

With explicit OAuth authorization, the application reads the following Google Health data for the authorizing account only:

  • Activity and fitness: steps, distance, calories, active minutes, heart-rate zones, exercise sessions
  • Health metrics and measurements: heart rate, resting heart rate, heart-rate variability, oxygen saturation, respiratory rate, weight
  • Sleep: sleep sessions, stages and efficiency
  • Profile: basic profile fields

Access is read-only. The application does not request write access to Google Health data.

How We Use Data

Data is used solely to display personal fitness insights, track trends over time, and adjust the operator's own training and nutrition plan. It is not used for advertising, not sold, not shared with third parties, and not used to train machine-learning models beyond the operator's personal calibration of recovery and strain estimates.

Google API Services User Data Policy — Limited Use

AiWong Fitness's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the user-facing features described above, is never transferred to third parties except as necessary to provide those features or to comply with applicable law, and is never used for serving advertisements.

Data Storage & Security

All data is stored on the operator's own computer. Nothing is transmitted to external servers beyond the OAuth handshake and read requests to Google's and WHOOP's official API endpoints. OAuth tokens are stored in files readable only by the operator's account. No third party has access to the stored data.

Data Retention & Deletion

Data is retained as part of the operator's personal training log until the operator deletes it. Because the operator is the only user, data deletion is performed by the operator directly. Google access can be revoked at any time at myaccount.google.com/permissions; revoking access stops all further data collection.

Changes

This policy may be updated as the application changes. The current version is always available at this address.
